Q: When does Git perform a fast-forward and when is a merge commit created?
A: Git performs fast forward only when source branch is based on the last commit of target branch. 

Q: What is the practical difference between merge and rebase?
A: Merge tries to combine several changes into one (octo strategy, for instance). Rebase changes "the" base of branch. 
Rebase also creates new commits because they have to be rewritten. Also it results in clear linear history
